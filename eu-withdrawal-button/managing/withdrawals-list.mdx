## Overview

The **Withdrawals** page lists every request your store has received. It's where you'll spend most of
your time managing day-to-day withdrawals.

## What the list shows

The list shows 25 requests per page, with the newest first. Each row includes:

| Column | What it shows |
| --- | --- |
| **Reference** | The unique ID for the request, e.g. `WD-2026-0001`. |
| **Order** | The related Shopify order number. |
| **Customer** | The customer's name. |
| **Status** | A badge showing the request's [compliance status](/eu-withdrawal-button/managing/withdrawal-detail#compliance-status). |
| **Amount** | The total value being withdrawn. |
| **Country** | The customer's country. |
| **Date** | When the request was submitted. |

## Actions on each row

<CardGroup cols={2}>
  <Card title="View" icon="eye">
    Opens the full details of the request — items, statuses, and the complete event timeline.
  </Card>
  <Card title="Delete" icon="box-archive">
    Archives the request so it no longer appears in the list. The record is retained behind the scenes
    for compliance purposes rather than permanently erased.
  </Card>
</CardGroup>

<Note>
If no withdrawals have been received yet, the page shows an empty state. New requests appear here
automatically as customers submit them.
</Note>
